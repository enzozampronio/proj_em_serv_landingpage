# Gestão de Projetos em Serviços (CAD8023, UFSC 2026.2)

Página de links da apresentação, publicada no GitHub Pages:
https://enzozampronio.github.io/proj_em_serv_landingpage/

- `index.html`: a página (HTML e CSS num arquivo só, identidade papel e tinta da EP-LOJA).
- `qrcode/`: QR code que leva à página, para o slide.
  - `qrcode.png` / `qrcode.svg`: tinta azul sobre papel.
  - `qrcode-contraste.png` / `.svg`: quase preto sobre branco, para projetor que desbota o azul.
  - `gerar.py`: refaz os QR codes. Se o endereço mudar: `python qrcode/gerar.py NOVA_URL`
    (precisa da biblioteca `qrcode`).
